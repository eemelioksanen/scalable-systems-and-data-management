# Initial PDF validation

Validated on 2 November 2026, from the issue-3 report sources based on `f28621890e77a18fd28791467406f4e3c2469652`. This is report-build evidence, not a new dataset experiment or final-report acceptance.

- `bash report/build.sh` completed in a task-only Podman 6.1.4 container, with compilation offline and limited to two CPUs and 2 GiB. The image uses the digest-pinned base in `Dockerfile` and Debian package repositories. The emitted `report/build/toolchain.txt` and `image.json` retain resolved versions and image identity.
- Observed toolchain: pdfTeX 1.40.26, TeX Live 2025/dev/Debian, `acmart` 2.12 dated 28 December 2024, latexmk 4.86. The installed class is distribution-packaged, not asserted to be the latest upstream release. Libertine, Inconsolata and newtx fonts loaded successfully. The first fallback-font build was rejected; adding the full fonts and plain-generic packages fixed missing fonts and `binhex.tex`.
- The final log and BibTeX log contain no warnings, undefined citations/references or overfull boxes. The PDF has three letter-size pages. The implementer visually inspected all three rendered `page-*.png` images after the final page-number and bibliography changes. Columns, tables, figure placeholders, citations, running headers and page numbers are legible and unclipped.
- `python3 report/export-overleaf.py` produced a report-only ZIP. Its extracted sources compiled independently with the same image, and all three pages' extracted text matched the main build exactly. A temporary nested-figure fixture also verified recursive figure inclusion and exclusion of build outputs. No external Overleaf account, compiler or project was exercised.
- JSON Schema draft 2020-12 validation accepted the experiment template. Focused negative checks rejected a missing subscriptions section and string-valued Flink parallelism. Shell syntax and `git diff --check` passed. Runtime application suites were not rerun because this change touches report tooling and documentation only.

The three-page skeleton is deliberately shorter than the final 4–5 page report. The documented five-page allocation reserves 1.5 pages for evaluation; finished prose, measured figures and member-authored reflections still require final pagination. Team names, ownership confirmation and the Overleaf project URL remain pending. The local PDF and PNGs are ignored outputs, not committed binaries.
